# Рекомендации вин: демо-приложение

Streamlit-приложение для сервиса, который рекомендует «хорошие» вина (оценка не ниже 7) по результатам лабораторного анализа. Модель логистической регрессии не обучается в приложении, а загружается из `model.joblib`.

## Содержимое папки

- `app.py` — приложение;
- `model.joblib` — обученный пайплайн (StandardScaler + LogisticRegression);
- `config.json` — порог по умолчанию;
- `test.csv` — тестовая выборка;
- `requirements.txt` — версии библиотек.

## Как запустить

Версия Python: **3.12.7** .

1. Создайте окружение: `python3 -m venv .venv`
2. Активируйте его: `source .venv/bin/activate`
3. Установите библиотеки: `pip install -r requirements.txt`
4. Запустите: `streamlit run app.py`

Приложение откроется по адресу http://localhost:8501.
